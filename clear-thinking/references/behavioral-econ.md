# 消费：识别定价与促销中的心理机制

用于帮用户在看商品页、促销、价格方案时，识别"哪些设计在影响判断"，再回到自己的真实需求。

## 常见机制

| 机制 | 表现 | 提问 |
|---|---|---|
| 锚定 | 划线原价、"立省X元"、先抛出一个高价 | 不看原价，这东西对我值多少钱？ |
| 免费 | "买一赠一""免费试用""满额赠" | 为了拿赠品，我是否多买了不需要的？ |
| 诱饵/对比 | 三档方案中间一档显得最划算；一个明显较差的选项衬托另一个 | 如果去掉那个"陪衬"选项，我还选这个吗？ |
| 稀缺/紧迫 | 限时、仅剩N件、倒计时、手慢无 | 这个紧迫是真的吗？错过它的真实损失是什么？ |
| 损失厌恶 | "不买就亏了""错过再等一年" | 我是在避免"损失感"，还是在获得需要的东西？ |
| 从众/社会认同 | 销量、好评、网红推荐 | 别人适合的，对我也适合吗？ |
| 沉没成本/承诺 | 已付定金、已填购物车、连续打卡 | 如果现在是第一次看到，我还会买吗？ |
| 心理账户 | "反正是奖金/优惠券/积分" | 这笔钱换成别的用途，我还愿意这样花吗？ |
| 订阅/低门槛 | 首月1元、自动续费 | 第二期起多少钱？取消难度如何？ |
| 拆分定价 | "每天只要X元" | 总价是多少？我真的会用满吗？ |

## 工作流程

1. 找出用户贴的内容中命中的机制（引用原文词句）。
2. 判断哪些是"正常商业手段"，哪些可能在明显影响理性判断，不要一概说成套路。
3. 帮用户还原一个"去掉促销包装"的判断：不看原价和赠品，这个东西本身值不值、我需不需要。
4. 用 4 个决策问题收尾，并给出建议：
   - 没有这次促销，我还想买吗？
   - 我有明确的需求和预算吗？
   - 对比过替代品/其他渠道吗？
   - 我能说出具体的使用场景吗？
5. 冲动风险低/中/高，对应建议：可以买 / 放购物车 24 小时 / 今天先别付款。

## 输出模板

**结论**：冲动风险 X；一句话原因。
**命中的机制**：机制 + 原文词句 + 一句解释。
**还原判断**：去掉包装后的真实问题。
**建议**：具体下一步（比价、等 24 小时、设上限、查退货/续费条款）。

## 注意

- 价格、政策、活动规则可能随时变化，涉及具体商家条款或当前价格，先联网核实，不凭记忆。
- 不做财务或投资建议；用户问到投资时，只提供分析框架和需要核实的事实，并说明自己不是理财顾问。
- 不评判用户"爱花钱"；目标是让他买得明白，不是不让他买。
